# Support

Ask questions and report bugs by opening an issue in the relevant repository. Use the Bug template
for something that does not behave as documented.

Security problems in public repositories go through private vulnerability reporting, see
[SECURITY.md](SECURITY.md). Private repositories have no reporting button; anyone with access to
one reports directly to the owner, never in an issue.

This is a one-person organization. There is no SLA, and replies come when time allows.
